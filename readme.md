# Task Manager App

A simple task management REST API built with **Java**, **Spring Boot**, **JWT Authentication**, **Lombok**, and **H2 Database**.

---

## Features

- JWT-based authentication
- User registration & login
- Create and retrieve tasks
- RESTful APIs with Spring Boot
- In-memory H2 database

---

## Tech Stack

- Java 17+
- Spring Boot 3.4.5
- Spring Security
- JWT (jjwt)
- Lombok
- H2 Database
- Maven

---

## Setup Instructions

### 1. Clone the Repository and Run the Application

```bash
git clone https://github.com/singshu647/task-manager.git
cd task-manager
./mvnw spring-boot:run
```
### 2. Use Postman or Curl to Test the APIs
- Postman collection: Task manager.postman_collection.json
- Swagger UI: http://localhost:8080/swagger-ui/index.html
